# Bodymorph Alterations review — 2026-10-24

The review covers all five active forms, their MCM, legacy mark/trainer scripts,
the ESP's properties and spell records, the tattoo catalog, and the enabled
NEFARAM installation. This is an offline code and installation review. No
in-game transformation or animation test was performed.

## Fixed issues

| Issue | Change |
|---|---|
| Each tattoo add/remove used `last=true`, causing repeated synchronization despite the outer batch | Queue mutations with `last=false`, silently, and synchronize once per apply/remove transition |
| Dispel/expiry could run cleanup while startup or a tier-up was still applying changes | Defer finish until that transition completes; cleanup runs once |
| Rapid startup stacks could both pass the empty-lock check before token allocation | Allocate through one guarded MCM controller and reserve the shared global before persistent token bookkeeping |
| Cleanup reversed actor values only while its shared token still matched | Reverse the instance's recorded stat deltas even after ownership is lost; only the current owner touches shared visuals and the lock |
| MCM's raw lock reset stranded stats; recovery reset the token after a fixed one-second delay | Lock-clear now uses recovery; wait up to 30 seconds for the owner to finish and preserve the lock if cleanup has not completed |
| Recovery removed permanent progression tattoos and could reset Feral's shared lock | Preserve progression marks, personal horns/hair, and Feral ownership |
| Tier-up removed every old modifier, including the whole bonus health pool, before reapplying | Apply only the difference between old and new modifiers; retain fire suppression during Troll tier-ups |
| Troll weapon-speed penalty was `-15.0` rather than `-0.15` | Use the intended fractional multiplier; existing recorded deltas still reverse by their recorded amount |
| Fire detection checked the incoming spell's own keyword rather than its magic effects | Check spell effects and OnMagicEffectApply; use an elapsed-effect timer for ten seconds of suppression |
| Dollform stripped tier-0 body clothing and ignored DD locks | Start body stripping at tier 1; all stripping forms recognize inventory and rendered DD keywords and skip empty slots |
| Cow horns could replace locked gear or remove horns already worn before casting | Check all overlapping slots; preserve pre-equipped horns; remove only copies added by the form |
| Repeated skeleton rebuilds ran during startup | Keep keyed BodyMorph model updates and remove duplicate QueueNiNodeUpdate/startup refresh passes |
| Progression added the nominal polling interval even when the VM was delayed | Accumulate the actual effect-clock difference at each update; older active effects initialize their new clock without double credit |
| Doll aura cooldown stored application uptime, which resets between Skyrim sessions | Use the effect clock and invalidate incompatible older timestamps |
| Cowform gave an immediate milk pulse on every cast | First production pulse follows the normal five-update interval, approximately 30 seconds |
| MCM tier controls skipped tiers 2 and 3, negative fractions displayed as positive, and debug edits could alter a live form's bookkeeping | Cycle through every tier, preserve the minus sign, and require an ended form before debug state edits |
| Build used temporary vanilla sources and borrowed Feral compile contracts | Use the durable repo vanilla tree and a local SkyUI contract checked against installed MCM Recorder; compile all 12 scripts and reject warnings |

Existing save-facing script names, properties, form IDs, spell durations, ESP,
and progression thresholds are retained. Legacy fields/functions remain where
useful for compatibility with existing script instances.

The follow-up pass also fixes four gameplay edges: lowering an MCM test tier
now synchronizes its use counter, Troll fire suppression applies immediately
when idle and expires at its remaining deadline without restarting polling on
every hit, the Troll attack-speed penalty covers both hands, and Cowform no
longer unequips manually worn horns after its own equip attempt was blocked.
The original installed mod has been updated in place under explicit user approval;
the temporary review override was archived outside MO2.
Deployment now also refuses a different installed ESP or any missing compiled
script before writing files or retiring an override.

## Validation

- All 12 Papyrus scripts compile with zero errors and zero warnings.
- Offline regression checks inspect transition/recovery guards and evaluate the
  actual stat formulas through repeated tier changes, restoration, suppressed
  regeneration, and independent actor-value changes.
- The direct ESP inspection validates attached PEX files, nonempty required
  object properties, local references, global/spell targets, five 420-second
  Lesser Powers, and the MCM startup SEQ quest.
- Every catalog texture exists in the project except the foot-nail texture,
  verified in the installed Apropos2 mod. No missing project textures found.
- MME's AssignSlot, CurrentSize, milk/lactacid argument signatures and actor-array
  properties were checked against its installed BSA's compiled scripts using
  ReSaver's read-only PEX parser. The lactacid return-type stub was corrected.
- A read-only save snapshot contained 10 active Papyrus threads, three function
  messages, and zero suspended stacks. No save edits or cleanup were performed.
  Local diagnostic details remain outside release content. This is a snapshot,
  not a guarantee of performance throughout gameplay.

## Installation and rollback

`build/Deploy.ps1` updates the existing `[NoDelete] Bodymorph Alterations` mod
from this project. Supply `-Mo2Root` or set `NEFARAM_MO2_ROOT` locally. The deployer
checks the selected NEFARAM profile, requires Skyrim/MO2 to be closed, backs up
replaced files and modlist.txt, then verifies every copied file. Existing source
copies are synchronized when present. Compile stubs and build tooling stay in
the repository. The ESP, plugin activation, saves, and base mod priority stay intact.

The earlier review override is removed from modlist.txt and archived outside MO2,
so only the existing mod remains installed. Restore the timestamped file/profile
backups to roll back, after ending any active form.

## Remaining limits and in-game checks

- Rabbitform's Fertility Mode integration remains detection-only. Troll artwork
  still reuses existing textures. These are unfinished features, not repaired
  by this script update.
- A lock or permanent stat alteration already orphaned by an older debug reset
  cannot be safely reconstructed from an unknown baseline. Recovery deliberately
  does not guess actor values or force-clear a live owner's token. If recovery
  reports that cleanup is still pending, close MCM, wait, and retry.
- The use counter is credited on updates; the final partial polling interval at
  an early fade is not credited. Finish deliberately avoids active-effect
  natives, which may already be unbound at natural expiry.
- Balance and visual feel still need gameplay testing, including high-tier
  combined body sliders and interactions with animation/equipment managers.

Recommended first session: cast each form, recast to fade, and verify the original
stats/body/hair return. Check a natural expiry, rapid recasting, a tier-up while
hurt, Troll fire followed by a tier-up, Cow horns with locked headgear, and a
save/reload while transformed. Open MCM recovery during a form and verify it
ends cleanly while progression marks remain. Feral should still block Bodymorph
casts and remain unaffected by Bodymorph recovery.
