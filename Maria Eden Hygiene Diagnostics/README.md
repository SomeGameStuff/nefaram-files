# Maria Eden Hygiene Diagnostics

A reversible loose-script diagnostic patch for Maria Eden Prostitution `d2026.8.9`.

After RaceMenu closes, the patch reports which RaceMenu Hand Paint nail overlay Maria matched, the raw tint value, RGB channels, alpha, calculated brightness, and the exact pass/fail reason. It also writes the full texture path to the Papyrus log under `@@ HYGIENE NAIL DIAG`.

Maria's original spoken dialogue and grooming rules are unchanged. The patch overrides only `MEP_PimpHygieneQuest.pex` and must have higher MO2 priority than Maria Eden Prostitution.

Run `Build-And-Deploy.ps1` to compile, validate, and deploy `[NoDelete] Maria Eden Hygiene Diagnostics`.
